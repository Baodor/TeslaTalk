# Changelog

## 0.1.0 · Preview

- Self-hosted React/FastAPI application with Docker Compose and Caddy/Traefik examples.
- Tesla OAuth, selected vehicles, profile and friendship/invitation flow.
- Private scheduled trips, live participant map, persistent chat and captured-data export.
- Named passenger QR/PIN access with server-enforced time bounds.
- Microphone-only LiveKit radio with push-to-talk and voice activation.
- Installable PWA, Tesla T/walkie-talkie icon and opt-in Web Push infrastructure.
- Separate OIDC admin overview and personal revocable API keys.
- German/English README, setup/API documentation, security and browser tests.

Real Tesla/browser compatibility and physical-device Push delivery remain acceptance checks. Charging planning, route commands, Immich uploads and the toilet-break button are planned additions.
